# AUTOLUXE HUB

A luxury car dealership website built as a hands-on DevOps learning project.

## What this project covers
- HTML/CSS frontend (car listings, contact form)
- Node.js + Express backend API
- Docker containerisation
- GitHub Actions CI/CD pipeline
- Cloud deployment with monitoring

## Project structure
- frontend/ — website pages and styling
- backend/ — Node.js API server
- docker/ — container configuration
- docs/ — project notes and diagrams

## Tech stack
HTML · CSS · Node.js · Docker · GitHub Actions
